# Fox

## AUTHORS

- Dave Long ([demaere-oiie](https://github.com/demaere-oiie/))

## ABOUT

Inspired by Henry Baker's COMFY, Fox blurs the lines between source
code and regular expressions.

Fox statements are combined with `<>` (alternation), `;` (sequencing),
and `Iter` (Kleene star).

The statements themselves are either mutations, of the form
(var0,var1... := val0,val1,...), or projections, of the form (val).
They can be guarded: (when **predicate** then **statement**). A
guarded statement plays the role of a literal range in a regular
expression.

### THEME

The `Iter` construct is unbounded; function evaluation proceeds by
keeping a worklist of continuation/environment pairs, and continually
unfolds until either (a) progress stops, or (b) an accepting state
is reached, in which case the most recent environment projection
will be returned.

## HOW TO USE

To build the language: `podman build . -t fox`

To run the sample programs:
```
> podman run -i fox < fac.fox
confirmed 5040
> podman run -i fox < gcd.fox
confirmed 15
```

### HOW `FAC` WORKS

The first statement of `fac` is a mutation, `acc := 1`. This adds
an accumulator to the environment, and sets it equal to 1. Only a
single worklist item will ever be generated by this statement.

The second statement of `fac` is an iteration of a mutation,
`Iter(n,acc:=n-1,n*acc)`. This generates an infinite number of
worklist items, as nothing prevents `n` from going negative.

Finally the third statement of `fac` is a guarded projection,
`when n<=1 then acc`, which provides the result of the function
immediately the worklist contains a continuation at this control
point where `n` in the environment is less than or equal to one.
